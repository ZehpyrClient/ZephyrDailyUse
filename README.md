# Zephyr Daily Use

Addon for Zephyr Vanilla that re-adds only the modules I currently use for daily play. This also does make the mod (in my opinion) not abusable, but use at your own discretion. 

Included modules: Disable Axe Stripping, Disable Block Particles, Disable Dead Mob
Interaction, Disable Dead Mob Rendering, Disable First-Person Particles, Disable
Fluid Fog, Disable Fog, Disable Nausea, Disable Portal GUI Closing, Disable Portal
Sound, Disable Rain, Disable Shovel Pathing, Disable Damage Tilt, Disable Explosion
Particles, Disable Particles, AppleSkin, ArmorRenderer, FullBright,
InventoryRenderer, Keybind Fix, Render Invisibility, Seedcracker,
ShulkerBoxTooltip, Mouse Tweaks, AuraMap, and Sneak.
